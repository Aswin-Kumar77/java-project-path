# Number Guessing Game

## 1. What the Project Does

A simple Java console game where the program generates a random number and the player tries to guess it.

The program gives feedback after each guess and continues until the correct number is guessed.

## 2. Java Concepts Used

- Variables and data types
- `Scanner` for user input
- `Random` for generating the number
- `while` loop
- `if / else` statements
- Comparison operators
- Basic methods

## 3. How to Run It

1. Clone or download the repository.
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Run `Main.java`.
4. Enter your guesses in the console.

## 4. What I Learned

- How to generate random numbers in Java.
- How to take user input using `Scanner`.
- How to use loops and conditions to control program flow.
- How to structure a small Java program from start to finish.
