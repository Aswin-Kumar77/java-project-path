# Java Project Path

A hands-on Java learning repository focused on improving implementation and software-building skills through small projects.

The goal is simple: **build, finish, learn, repeat.**

## Purpose

This repository is a collection of progressively more challenging Java projects.

Instead of only studying Java concepts theoretically, each project is built from scratch to practice:

* Turning ideas into working programs
* Applying Java concepts in real code
* Structuring programs
* Problem-solving
* Debugging
* Finishing projects independently

## Project Path

Projects will gradually increase in complexity.

### Completed

* **Simple Calculator** — Basic arithmetic operations and user input
* **Quiz Game** — Loops, methods, parameters, return values, input handling, and score tracking

### Upcoming

More projects will be added progressively, with each project introducing new implementation challenges.

## Learning Approach

Each project is intentionally small.

The focus is not on building the most sophisticated version possible, but on:

1. Understanding the requirements
2. Designing a basic solution
3. Implementing it independently
4. Debugging problems
5. Finishing the project
6. Moving on to the next challenge

Complexity will increase over time.

## Technologies

* Java
* IntelliJ IDEA
* Git
* GitHub

No frameworks or external libraries are used unless a future project specifically requires them.

## Long-Term Goal

Build enough practical Java experience to eventually create a substantial project from scratch.

The final goal is a **Java game engine**, built without relying on cloud services or unrelated technologies.
