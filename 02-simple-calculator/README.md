\# Simple Calculator



A simple console-based calculator written in Java.



\## Features



\* Addition

\* Subtraction

\* Multiplication

\* Division

\* User input using `Scanner`

\* Displays the calculated result

\* Handles basic arithmetic operations



\## Concepts Practiced



\* Variables and data types

\* `Scanner`

\* Methods

\* `if / else`

\* `switch`

\* User input

\* Arithmetic operators

\* Basic Java program structure



\## How It Works



The program takes two numbers and an arithmetic operator from the user, performs the selected operation, and displays the result.



```text

First number

&#x20;    ↓

Operator

&#x20;    ↓

Second number

&#x20;    ↓

Perform calculation

&#x20;    ↓

Display result

```



\## Running the Project



Compile and run the Java program:



```bash

javac Calculator.java

java Calculator

```



\## Example



```text

Enter first number: 10

Enter operator: \*

Enter second number: 5



Result: 50

```
