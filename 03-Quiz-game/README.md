\# Quiz Game



A simple console-based quiz game written in Java.



\## Features



\* 5 multiple-choice questions

\* User input using `Scanner`

\* Immediate correct/wrong feedback

\* Score tracking

\* Final score display

\* Uses a `for` loop to process the questions

\* Uses a reusable method to check answers



\## Concepts Practiced



\* Variables and primitive data types

\* `Scanner`

\* `if / else if / else`

\* `for` loops

\* Methods

\* Parameters and arguments

\* Return values

\* Basic program structure



\## How It Works



The program displays each question with four possible answers. The player enters the number corresponding to their choice.



The selected answer is passed to the answer-checking method along with the correct answer and current score.



```text

Question

&#x20;  ↓

User input

&#x20;  ↓

Check answer

&#x20;  ↓

Update score

&#x20;  ↓

Next question

&#x20;  ↓

Final score

```



\## Running the Project



Compile and run the Java program:



```bash

javac QuizGame.java

java QuizGame

```
